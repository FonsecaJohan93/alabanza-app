# Alabanza

App web del equipo de alabanza: repertorio compartido, acordes importados desde
LaCuerda o pegados desde Cifra Club, transposición y vista solo letra.

React + Vite + Tailwind, con Netlify Functions y Netlify Blobs. Ver `CLAUDE.md`
para detalles técnicos. Todos los derechos reservados (ver `LICENSE`).
